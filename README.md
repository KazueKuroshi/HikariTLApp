# Translate Novel App

Aplikasi Android sederhana yang menerjemahkan novel yang di-hosting di GitHub Pages menggunakan Google Translate API.

## Fitur
- Masukkan teks untuk diterjemahkan
- Menampilkan teks terjemahan
- Mengambil konten novel dari GitHub Pages

## Persyaratan
- Android Studio
- Kunci API Google Translate

## Setup
1. Clone repositori.
2. Buka proyek di Android Studio.
3. Tambahkan kunci API Google Translate Anda di `TranslationService.kt`.
4. Jalankan aplikasi di emulator atau perangkat fisik.
